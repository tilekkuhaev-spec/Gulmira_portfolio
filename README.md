# Омарова Гульмира Мукановна — сайт-портфолио

Ағылшын тілі мұғалімі. Айнабұлақ ауылының №31 жалпы білім беретін мектебі. Педагогикалық өтілі — 6 жыл, санаты — педагог-модератор.

## Сайтты компьютерде ашу

1. ZIP архивін толық ашыңыз.
2. `index.html` файлын браузерде ашыңыз. Қалған бумалар осы файлдың жанында тұруы керек.

Сайтқа қосымша бағдарлама, сервер немесе ақылы қызмет қажет емес. Интернетсіз компьютерде де ашылады. Телефоннан сайтты GitHub Pages сілтемесі арқылы ашқан ыңғайлы.

## GitHub Pages-ке орналастыру

1. GitHub-та жаңа репозиторий жасаңыз. Мысалы, атауы: `gulmira-portfolio`.
2. **Add file → Upload files** арқылы архивтен шыққан файлдарды жүктеңіз. Репозиторийдің негізгі деңгейінде `index.html` тұруы керек. ZIP-ті тұтас жүктемеңіз.
3. GitHub браузер арқылы бір жолы 100 файлға дейін қабылдайды. Сондықтан жүктеуді төрт рет жасаңыз: алдымен негізгі деңгейдегі файлдар, одан кейін `assets`, `documents`, `previews` бумаларының әрқайсысын бөлек жүктеңіз. Әр буманы атауын сақтап, толық күйінде сүйреп апарыңыз. Әр жүктегеннен кейін өзгерістерді сақтаңыз.
4. **Settings → Pages** бөліміне өтіңіз.
5. **Source → Deploy from a branch**, тармақ **main**, бума **/(root)** таңдаңыз. **Save** басыңыз. Тармақтың атауы басқа болса, файлдар тұрған тармақты таңдаңыз.
6. Жариялау аяқталған соң сол бетте сайттың сілтемесі пайда болады. Сол сілтеме телефонда да, ноутбукте де ашылады.

Егер GitHub Desktop қолдансаңыз, барлық файлды бір ретпен жүктеуге болады. Арнайы құрастыру командасы қажет емес.

Ресми нұсқаулықтар: [GitHub-қа файл жүктеу](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository), [GitHub Pages баптауы](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Сайтта не бар?

- Мұғалім туралы берілген мәліметтер және жіберілген сурет.
- Бастапқы архивтегі барлық **61 PDF құжат, 68 бет**.
- Мұғалім жетістіктері — 23 құжат.
- Оқушы жетістіктері — 24 құжат.
- Біліктілік — 4 құжат.
- Жарияланымдар — 9 құжат.
- Авторлық жұмыс — 1 құжат.
- Құжат атауы мен оқушы аты бойынша іздеу, бөлімдер бойынша сүзу.
- PDF орнатпай-ақ беттерді көру, үлкейту, бұру және PDF жүктеу.

Құжаттардың жеңілдетілген көшірмелері берілген, бет саны сақталған. Бастапқы архивті түпнұсқа ретінде өзіңізде сақтаңыз.

## Файлдардың құрылымы

| Файл немесе бума | Мазмұны |
| --- | --- |
| `index.html` | Басты бет және құжаттар каталогы |
| `assets/styles.css` | Телефонға, планшетке және компьютерге бейімделген безендіру |
| `assets/app.js` | Іздеу, сүзу және құжаттарды көру |
| `assets/documents.js` | Барлық құжаттың атауы, бөлімі және файл жолдары |
| `assets/portrait.jpg` | Жіберілген мұғалім суреті |
| `assets/thumbnails/` | Каталогтағы шағын құжат суреттері |
| `documents/` | Барлық 61 PDF |
| `previews/` | Телефонда және компьютерде қарауға арналған барлық 68 бет |
| `FILE_INDEX.csv` | Бастапқы файлдар мен сайттағы файлдардың сәйкестік тізімі |
| `.nojekyll` | GitHub Pages-ке арналған қызметтік файл |

## Кейін мәліметтерді өзгерту

- Аты-жөні, өтілі, санаты және мектеп атауы — `index.html` ішінде.
- Сурет — `assets/portrait.jpg`. Осы атаумен жаңа сурет салуға болады.
- Түстер — `assets/styles.css` файлының басындағы айнымалыларда.
- Құжат атаулары — `assets/documents.js` ішінде. PDF пен көрініс файлдарын өшірмеңіз.

Барлық сілтеме салыстырмалы берілген. Сайт GitHub Pages-тегі репозиторий бумасында да жұмыс істеуге дайын. Сыртқы қаріптер, жарнама, аналитика және бөгде скрипттер қолданылмаған.
